# Pocketdump

Transfer photos and videos from iPhone to PC over local WiFi.

## npm Commands

| Command | What it does |
|---|---|
| `npm install` | Install dependencies (once, or after pulling changes) |
| `npm start` | Launch the app normally |
| `npm run build` | Build a Windows installer |

No `dev` script — use `npm start` during development too. See the full
[npm cheat sheet](../NPM-CHEATSHEET.md) for how this compares to other
projects.
