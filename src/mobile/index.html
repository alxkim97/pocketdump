Or build it from scratch
  1. Open the Shortcuts app, tap +, and name the shortcut "PocketDump".
  2. Tap the ⓘ button, turn on Show in Share Sheet, and set it to receive Images and Media.
  3. Add a Repeat with Each action, repeating over Shortcut Input.
  4. Inside the repeat, add Get Contents of URL. Paste the address above, set Method to POST and Request Body to Form, then add a File field named file set to Repeat Item.
  5. Optional: add a Text field named lastModified set to Repeat Item's Creation Date (Date Format: ISO 8601), so each photo is filed under the day it was taken.

Take photos and queue them up, then send the batch to your PC.
